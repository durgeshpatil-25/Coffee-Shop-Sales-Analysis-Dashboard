# Coffee Shop Sales Dashboard

## Overview
This dashboard provides an interactive analysis of coffee shop sales performance, customer footfall, product trends, and order behavior. It helps in understanding customer preferences, peak sales hours, and store performance through visual insights.

---

## Key Insights
- Total Sales: **$698,812.33**
- Total Footfall: **149,116**
- Average Bill per Person: **4.69**
- Average Orders per Person: **1.4**

### Business Highlights
- **Coffee** contributes the highest sales distribution with **39%** share.
- Peak order hours are between **8 AM to 10 AM**.
- **Friday** recorded the highest number of weekly orders.
- **Large** and **Regular** size orders dominate customer preferences.
- **Hell's Kitchen** store generated the highest sales among all locations.
- **Barista Espresso** is the top-selling product based on sales.
